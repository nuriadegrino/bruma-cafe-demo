# Bruma Café — Premium Website Demo

Concept website for a fictional specialty coffee shop in Lleida. Created as a portfolio project to demonstrate premium web design, responsive UX and conversion-focused structure.

## Goals

- Make table reservations the primary conversion.
- Communicate a premium but warm brand.
- Work comfortably on desktop, tablet and mobile.
- Keep typography readable and editorial.
- Demonstrate a professional restaurant/café landing page without external frameworks.

## Features

- Responsive navigation and mobile menu.
- Reservation CTA throughout the customer journey.
- Mobile sticky reservation button.
- Responsive reservation form with demo confirmation flow.
- Semantic HTML and accessible labels.
- Keyboard focus styles.
- Reduced-motion support.
- SEO title and description.
- Open Graph metadata prepared for publication.
- Local business structured data.
- Custom SVG favicon.
- Responsive image loading and lazy loading for secondary imagery.
- Premium editorial typography.
- Subtle hover interactions.

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Unsplash imagery for the conceptual demo

## Important

Bruma Café is a fictional concept. The address, phone, email, menu, availability and reservation flow are demonstration content. The reservation form does not create real bookings.

For a real client project, connect the reservation CTA/form to the restaurant's booking provider, WhatsApp, email workflow or backend and replace all fictional business information.

## Local preview

Open `index.html` directly in a browser, or serve the folder with a local development server.
